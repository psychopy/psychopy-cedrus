RipondaSoundSensorGroup
-------------------------------

To import RipondaSoundSensorGroup (the Riponda's voice key), you can either use:
```python
from psychopy_cedrus.riponda import RipondaSoundSensorGroup
```
or, any time after `psychopy.plugins.activatePlugins` has been called:
```python
from psychopy.hardware.cedrus import RipondaSoundSensor
```
