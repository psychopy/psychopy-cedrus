RipondaDevice
-------------------------------

To import RipondaDevice, you can either use:
```python
from psychopy_cedrus.riponda import RipondaDevice
```
or, any time after `psychopy.plugins.activatePlugins` has been called:
```python
from psychopy.hardware.cedrus import RipondaDevice
```
